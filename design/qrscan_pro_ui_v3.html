03 macOS · 原生 SwiftUI macOS 14+
macOS 使用 NavigationSplitView + 原生 List(.sidebar)。Form 在 macOS 上自动渲染为 macOS 偏好设置风格。Form 的代码与 iOS 完全相同，跨平台 0 适配。链接打开使用 NSWorkspace.shared.open 调用系统默认浏览器。
跨平台共享：设置页、生成历史的列表代码与 iOS 完全一样，由 SwiftUI 自动渲染为对应平台样式。识别页是 macOS 独有，使用 .fileImporter 标准文件选择器和 .dropDestination 拖拽 API。
